# Weather dashboard
Showing visualizations of weather data with a dashboard.
Flask server can be opened with CLI command 
'python app.py'. The dashboard can be opened with a browser.

# Investigate data
Showing data in browser can be done by with CLI command
'python server.py' and using route /data 

# Making new models
Modelling can be done by first preprocessing the data using R code
found from the folder 'R'. 

Models are created using different types of python model scripts found in the folder 'modelling'.
Running a script generates a pkl model file to the 'modelling' folder which contains all the model information.

The predicted temperature values can be seen in the weather dashboard.
